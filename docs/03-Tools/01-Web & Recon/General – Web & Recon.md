## 📝 Notas

- **CrackStation:** opción inicial para comprobar hashes comunes o débiles.
- **Hashes.com:** útil cuando no se conoce con certeza el algoritmo utilizado.
- **CyberChef:** puede utilizarse para analizar hashes mediante **Analyze hash** y realizar diferentes transformaciones y decodificaciones.
- **JWT.io:** útil para inspeccionar la estructura de tokens JWT, incluyendo Header, Payload y Signature.
